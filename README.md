## 📖 About

**Quote Generator** is a simple, elegant web app that serves up a fresh motivational quote every time you click a button. It comes with **10 handpicked quotes**, a smooth **pop-up animation** when a new quote appears, and a calm **Starry Night** themed background.

Built as a beginner-friendly project to practice **DOM manipulation**, **arrays** and **event handling** in vanilla JavaScript.

## ✨ Features

- 🎲 **10 handpicked quotes** stored in a JavaScript array
- 🔘 **"New Quote" button** to load the next quote instantly
- 🪄 **Pop-up animation** every time a quote appears
- 🌌 **Starry Night background** for a calm, aesthetic look
- 🖱️ **Hover effect** on the quote card
- ⚡ **Lightweight**, with no frameworks or libraries and no installation

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure |
| **CSS3** | Styling, background, hover and pop-up animation |
| **JavaScript (ES6)** | Quote logic and button click handling |

## 🚀 Getting Started

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mayankrajbhargit/quote-generator.git
   ```
2. **Open the project folder**
   ```bash
   cd quote-generator
   ```
3. **Run it** by opening `qoute.html` in your browser, or use **Live Server** in VS Code.

## 🧠 How It Works

1. All 10 quotes are stored in an array in `qoute.js`.
2. When the **New Quote** button is clicked, the app picks the next quote.
3. The quote text is updated in the DOM.
4. A CSS animation plays, so the quote **pops up** on screen.
